Common topics

  • Photos permission — Settings → PlatMemoir → Photos: allow access so footprints can load.
  • Google Takeout — Import metadata JSON and, for previews, reconnect the Takeout image folder in Settings.
  • Switching users on a shared iPad — Export a handoff backup before clearing data; restore the correct .zip for each person.
  • Exports — Story ZIP, map snapshot, travel plan PDF, and achievement PDF are created on device and shared via the system share sheet.
